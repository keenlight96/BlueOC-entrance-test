# Post Management App

## Features

- Fetch posts from API
- Display posts in a table
- Add new posts to the table
- Uses Redux for state management and API calls

## Tech Stack

- React (Vite)
- Redux
- Tailwind CSS

## Installation

### 1. Install dependencies

```
npm install
```

### 2. Run the server

```
npm run dev
```
